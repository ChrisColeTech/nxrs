## Built

Implemented an opt-in **diagnostic**, not a causal MKW correction. Source/evidence did not demonstrate that the
faulting draw violates a resource-lifetime or descriptor-bounds invariant.

- `exec.rs`: captures the actual address/range supplied to `vkGetDescriptorEXT` (including zero fallback), buffer
  handle/offset, descriptor binding/type, shader key, stage, submission serial, descriptor chunk/offset, ownership
  and pool epoch. Immutable snapshots survive stage-set cache hits. The selected snapshot must match submission,
  chunk, offset, stage and shader; a mismatch becomes explicitly missing evidence.
- `lost.rs`: returns the checkpoint token to its caller. Mesh recording carries that token across setup, including
  intervening pass/upload checkpoints, and records a draw only at an actual mesh command emission. The driver
  address-binding callback supplies monotonically increasing observed binding IDs; lookup requires both buffer
  handle and a containing observed range. Missing IDs stay unknown. Existing address/name history is preserved.
- `lost_bindings.rs`: retains immutable CPU snapshots and binding IDs observed at encoding and command issue;
  reports the current observed ID at loss. Retention is FIFO, capped at 16,384 draw records **and** 16 MiB of
  conservatively charged record/snapshot payload (shared snapshots are charged per draw). Per-stage snapshots cap
  buffer/texel-buffer descriptors at 64, with an explicit omitted count. A queue retains at most seven current stage
  snapshots outside that history budget; container/allocator overhead is additional and bounded by the entry cap.
- Loss output reports up to 64 checkpoint-associated draws and separates **CONTAINING**, **NEAREST-OUTSIDE
  (OOB candidate only)**, other outside, and invalid/unknown ranges. Half-open range arithmetic is checked for
  overflow. Evictions, missing stages/ranges and absence of a snapshot at the top checkpoint are explicit.

Enable only in a separately authorized discriminator run with `NXGFX_MESH_BINDINGS=1`, checkpoint support enabled
(`NXGFX_CHECKPOINTS=all` recommended) and `NXGFX_ADDR_REPORT=1`. This adds CPU metadata only: no extra GPU commands,
readbacks, shader changes or guest-memory reads. The existing descriptor-buffer backend is the scoped target;
classic descriptor sets produce missing-stage evidence rather than fabricated ranges. `issue` means CPU command
recording, not that the GPU has executed the draw. Global pool epochs are not individual allocation generations.
